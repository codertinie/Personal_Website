# Martin Munyao — Developer Portfolio 🚀

Welcome to my personal developer portfolio! Built with **React**, this site showcases who I am, what I do, and the projects I'm most proud of.

---

## 🔍 Overview

This portfolio includes:

- ✅ Hero section with call-to-action
- ✅ About Me with Skills & Experience
- ✅ Portfolio section with sample projects
- ✅ Blog section for dev insights and tutorials
- ✅ Contact form
- ✅ Responsive footer with social links

---

## 🛠️ Tech Stack

- React.js
- CSS Modules
- React Icons
- Hosted on [Vercel](https://vercel.com/)
- Designed with love 💙 and code 💻
